# Инструменты для тестирования CRM

## Секреты

`npm run audit:secrets` проверяет историю Git через Gitleaks. Конфигурация
`.gitleaks.toml` оставляет правила по умолчанию и исключает только UUID тестовых
записей, которые общий эвристический фильтр ошибочно считает API-ключами.
Та же проверка идёт в CI внутри закреплённого по digest контейнера с отключённой
сетью и доступом к репозиторию только на чтение. На Mac Gitleaks можно установить
через Homebrew. Проверка не заменяет отзыв и перевыпуск реально утекшего ключа.

## Неиспользуемый код

`npm run audit:unused` запускает Knip. Его список — кандидаты на ручную проверку,
а не команда на автоматическое удаление. В этом проекте часть скриптов запускается
динамически из npm/Docker, поэтому Knip может считать рабочий файл неиспользуемым.
Перед удалением нужно проверить ссылки поиском, затем запустить lint, typecheck,
unit-тесты и сборку.

## Сбой браузерного сценария

`npm run test:uploads-browser` теперь сохраняет `failure.png` и
`failure-trace.zip` в каталоге `artifacts/uploads` при падении. Для S3-сценария
каталог задаётся через `UPLOAD_CHECK_ARTIFACTS`. Trace можно открыть локально
через `npx playwright-core show-trace <путь-к-файлу>`; в нём бывают снимки
страниц и сетевые запросы, поэтому его нельзя публиковать или пересылать без
проверки содержимого. При успешном тесте trace не сохраняется.

## Внешняя резервная копия

Restic установлен на рабочем Mac как кандидат для отправки уже проверенных
архивов CRM на независимое хранилище. До выбора адреса хранилища, настройки
ключей и пробного восстановления внешнее резервирование **не работает**.
Нельзя считать локальный каталог бэкапов или второй каталог на том же сервере
независимой копией. Копировать следует готовый архив CRM целиком, не отдельный
`pg_dump` и каталог документов, снятые в разное время.

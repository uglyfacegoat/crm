# Проверка файловых входов (UP-01)

24 сентября 2026. Аудит по исходникам и собранному standalone-серверу на одноразовой PostgreSQL. Проверены девять пользовательских потоков из [карты файловых записей](STORAGE_WRITERS.md); иных upload-маршрутов в `src/app` не найдено. Общий предел тела Server Action — 16 МиБ, отдельного файла — 15 МиБ (фото группы — 3 МиБ). Перед `arrayBuffer()` каждый поток сравнивает `File.size` с соответствующим пределом. Тело также ограничено в Proxy; подробная проверка этого уровня — [UP-06](UPLOAD_PERIMETER_MATRIX.md).

| Поток | Серверная проверка | Разрешённый формат | Ключ хранения |
| --- | --- | --- | --- |
| Документ и новая версия | `assertDocumentFileSize`, `validateDocumentFile` | PDF, JPG/JPEG, PNG, WebP, DOCX, XLSX | Организация / UUID документа / номер версии + проверенное расширение |
| Чек оплаты и выплаты | Те же проверки в `storeReceipt` | Те же форматы | Организация / UUID чека / v1 + проверенное расширение |
| Закрывающий акт | Общая проверка, затем исключение Office | PDF, JPG/JPEG, PNG, WebP | Организация / UUID акта / v1 + проверенное расширение |
| Фото выезда | Общая проверка, затем только изображение | JPG/JPEG, PNG, WebP | Организация / UUID материала / v1 + проверенное расширение |
| Шаблон документа | Общая проверка, затем только PDF/DOCX | PDF, DOCX | Организация / UUID шаблона / v1 + проверенное расширение |
| Вложение чата | `validateChatAttachment`; размер до чтения | Общие документы/изображения и WebM, M4A, MP3, WAV | Организация / UUID сообщения / v1 + проверенное расширение |
| Фото группы | `validateChatAvatar`; размер 3 МиБ до чтения | JPG/JPEG, PNG, WebP | Организация / UUID группы / номер версии + проверенное расширение |

Файл не задаёт путь хранения: исходное имя используется только как безопасное отображаемое имя. Расширение для ключа берётся из результата серверной проверки, идентификаторы — из проверенного входа/сессии, а local- и S3-адаптеры независимо отвергают ключ вне строго заданного формата. Проверка файла сопоставляет расширение, заявленный MIME и начальную сигнатуру; Office ZIP дополнительно разбирается с ограничением числа файлов и распакованного объёма ([UP-03](FILE_MALWARE_SCANNING.md)). Неизвестные расширения и несовпадающие типы отклоняются. Вариант `.jpeg` нормализуется в `.jpg` для хранилища.

Проверки: unit-тесты отклоняют подмену MIME, расширения и сигнатуры, исполняемое имя, неподходящее фото группы и превышение 3/15 МиБ. Браузерный тест на собранном сервере прошёл 18 реальных загрузок во всех девяти семействах, девять состояний ошибки после сохранения и файл ровно 15 МиБ с проверкой сохранённых байтов и SHA-256. Тест запускается с одноразовой БД и временным файловым каталогом; постоянная Docker-БД не менялась.

Граница проверки: начальная сигнатура не доказывает, что PDF, изображение или аудио полностью корректны и безопасны; ограниченный разбор ZIP также не проверяет смысл внутреннего Office-документа. Остаточные испытания повреждений и вложенных архивов — `UP-03`, антивирусного режима на выбранном сервере — `UP-02`. Конкурентная память и ZIP/preview под нагрузкой — `UP-05`.

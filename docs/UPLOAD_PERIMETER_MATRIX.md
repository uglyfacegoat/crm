# Периметр загрузок и публичной интеграции (UP-06)

Проверено 24 сентября 2026 на собранном standalone-сервере и одноразовой PostgreSQL. Это матрица входов, через которые сейчас принимаются файлы или публичные заявки. Поиск `File`, `arrayBuffer()` и `formData.get()` в `src/app` выявил перечисленные ниже семейства; иных маршрутов записи файла сейчас нет.

| Вход | Что загружается | Origin и Host | Тело и файл | Ограничение запросов |
| --- | --- | --- | --- | --- |
| `/documents`, Server Actions `uploadDocumentAction` и `uploadDocumentVersionAction` | Документ и новая версия | Общий `proxy.ts`: только разрешённый Host и тот же Origin | 16 МиБ на всё тело, 15 МиБ на файл; размер проверяется до `arrayBuffer()` | `document_upload`: 20/мин на сотрудника и 200/мин на компанию |
| `/calendar`, `completeVisitAction` и `uploadVisitEvidenceAction` | Подписанный акт и фото выезда | То же | То же | `document_upload` |
| `/finance`, `createPaymentAction` и `createPayoutAction` | Чек оплаты/выплаты | То же | То же | `document_upload` |
| `/settings`, `uploadDocumentTemplateAction` | Шаблон акта | То же | То же | `document_upload` |
| `/chat`, `sendChatMessageAction` и `updateChatChannelSettingsAction` | Вложение и фото группы | То же | 16 МиБ на тело; 15 МиБ на вложение, 3 МиБ на фото группы; размер до `arrayBuffer()` | `chat_upload`: 10/мин на сотрудника и 100/мин на компанию; также действуют лимиты сообщения/действия |
| `/api/v1/webhooks/website-leads`, `POST` | JSON-заявка сайта | Разрешённый Host; Origin не требуется для внешнего сервера, обязательный Bearer secret | Потоковый предел 32 КиБ, в том числе без `Content-Length`; неверный JSON отклоняется | 600/мин глобально, 120/мин на доверенный IP, 120/мин на сайт |

Next.js Proxy по умолчанию обрезал тело на 10 МиБ, хотя приложение принимало файл до 15 МиБ. `proxyClientMaxBodySize` поднят до 17 МиБ, то есть выше 16 МиБ Server Action. Сам `proxy.ts` считает байты тела Server Action и multipart-запроса, включая запросы без `Content-Length`, и возвращает HTTP 413 при превышении 16 МиБ. Проверка стоит после отказа по Host/Origin, поэтому чужой источник не заставляет приложение читать большое тело. Перед чтением файла в память проверяется его размер; для документов и шаблонов бюджет загрузок проверяется тоже до `arrayBuffer()`.

Проверки:

- `scripts/perimeter-check.mjs` на production runtime: отсутствующий, `null` и чужой Origin для каждой страницы загрузки; поддельные Host/forwarded Host; исключение для Bearer-webhook.
- `scripts/request-body-check.mjs`: объявленный и потоковый (без `Content-Length`) слишком большой запрос Server Action и обычной multipart-формы получает 413; JSON-маршруты проверены на границе размера, невалидном UTF-8 и ошибках формата.
- `scripts/uploads-browser-check.mjs`: настоящий файл ровно 15 МиБ проходит через браузер, Proxy и Server Action без обрезки; байты и SHA-256 совпадают с сохранённой версией. Сохранены обычные сценарии документов, чеков, шаблона, чата и выездов.
- `scripts/request-limits.integration.mjs` проверяет конкурентные бюджеты сотрудника и компании и разделение компаний; `scripts/website-webhook-limits.check.mjs` проверяет глобальный/IP-бюджет и недоверенные forwarding-заголовки.

Этот пункт не закрывает проверку опасного содержимого (`UP-02/03`) и общий предел конкурентных тяжёлых запросов (`UP-05`). Proxy временно буферизует тело до 17 МиБ **на один запрос**; память при одновременных загрузках требует отдельного нагрузочного испытания.
